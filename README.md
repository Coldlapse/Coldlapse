<h2 align="left">Finished Projects</h2>

###

<ul align="left">
  <li>
    <strong><a href="https://github.com/Coldlapse/PixelZoom" target="_blank">PixelZoom</a></strong> (Web Service Live since September 1, 2026 — <a href="https://pixelzoom.app" target="_blank">pixelzoom.app</a>)<br>
    Developed an algorithm that enables scaling of pixel art without damaging its block structure, unlike standard integer-ratio scaling. Implemented a working zoom tool using OpenCV. The web service, built with the <a href="https://github.com/PixelZoom-Team" target="_blank">PixelZoom-Team</a>, went live on <strong>September 1, 2026</strong> and is now publicly available at <a href="https://pixelzoom.app" target="_blank">pixelzoom.app</a>. The underlying algorithm was published in <em>Applied Sciences</em>.
  </li>
  <br>
  <li>
    <strong><a href="https://github.com/Coldlapse/beatmania.app" target="_blank">beatmania.app</a></strong> (Live Service since Q4 2022 — <a href="https://beatmania.app" target="_blank">beatmania.app</a>)<br>
    Cloned from <a href="https://github.com/kuna/iidxranktable" target="_blank">kuna/iidxranktable</a> and refactored for compatibility with Python 3.xx. Added new features such as dark mode and LEGGENDARIA chart difficulties. Also fixed broken features including DJ RANK record tracking. The service has been running continuously as a live service since <strong>Q4 2022</strong>. As of Q3 2026, all planned development is complete, and the project will move into <strong>maintenance mode</strong> starting Q4 2026.
  </li>
  <br>
  <li>
    <strong><a href="https://github.com/2025-OSS-Project" target="_blank">Geomemo</a></strong><br>
    Contributed as a backend developer. Designed the backbone of the backend API, with a strong focus on privacy-related user experience features such as “visibility” and “access scope” settings. Later implemented the follow system to enhance user interactions.
This project was also my first experience working in a structured collaboration environment with dedicated roles such as a platform/deployment manager, and practices like PR/issue workflows. I was able to see firsthand how systematic collaboration boosts both efficiency and productivity.
  </li>
  <br>
  <li>
    <strong><a href="https://github.com/Coldlapse/pill-bg-remover" target="_blank">pill-bg-remover</a></strong><br>
    Developed as a module for a capstone design project. Fine-tuned the U²-Net model included in the <a href="https://github.com/danielgatis/rembg" target="_blank">rembg</a> library to build a preprocessor that isolates pills in photos by removing the background.
  </li>
  <br>
  <li>
    <strong><a href="https://github.com/Coldlapse/IIDXwidget" target="_blank">IIDXwidget</a></strong> (Landing Page — <a href="https://iidxwidget.coldlapse.dev" target="_blank">iidxwidget.coldlapse.dev</a>)<br>
    Developed an Electron app that runs a local server to replicate <a href="https://rag-oji.com/dakendisplay/" target="_blank">Rag's button input counter</a> for dual-PC streaming environments. The output can be integrated into OBS via a browser source. Development began in <strong>April 2025</strong>; with the <a href="https://github.com/Coldlapse/IIDXwidget/releases/tag/v3.0.0" target="_blank">v3.0.0 release</a> in <strong>September 2026</strong>, the program is considered feature-complete and has entered <strong>maintenance mode</strong>.
  </li>
  <br>
  <li>
    <strong><a href="https://github.com/Coldlapse/HJ-QueueCounter" target="_blank">HJ-QueueCounter</a></strong><br>
    Implemented a hardware and software system to monitor the number of users in the queue for arcade game machines. In collaboration with 'Hwajeong Game Land' in Goyang-si, South Korea, the custom-built solution was successfully deployed and operated on a beatmania IIDX Lightning Model cabinet.
  </li>
</ul>
